Vermillio Report Augmentation

Process a Google Sheet's report tab. Reads URLs from the page_url column and writes normalized metadata back into the same row. Uses the same backend endpoints as the CSV Generator.

Setup & column mapping

Share your Sheet with this service account (Editor access):
vermillioserviceaccount@vermillio.iam.gserviceaccount.com

The report tab is read from / written to. Columns are matched by header name (column position doesn't matter). These headers are written when present:

title          ← title (normalized)
content_url    ← heroImageUrl
handle         ← channelHandle   (blank if N/A)
duration       ← durationSeconds (blank if N/A)
view_count     ← viewCount
published_date ← publishedAt
like_count     ← likeCount
comment_count  ← commentCount
tagged_music   ← taggedMusic     (TikTok + Instagram only, "Artist - Song Title", blank otherwise)

Headers missing from your Sheet are skipped silently. Only page_url is required. Rows where final_relevance is FALSE or final_authorized is TRUE are skipped (already triaged). Rows whose URL can't be processed are skipped entirely — nothing is written and existing cell content is preserved.

client_category_override is written with source_authorized when the row's handle or page_url's domain matches an entry in the team's source-authorization reference sheet — it's never blanked otherwise, since this column may also hold unrelated manual overrides.
